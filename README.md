# Morning & Evening Dhikr

Application mobile et Web « Adhkar du Matin et du Soir »

Crée une application moderne disponible sur Android, iPhone (iOS) ainsi qu’une version Web responsive.

Le design doit être épuré, moderne, élégant, inspiré des applications islamiques premium, avec un thème clair et sombre.

L’objectif est d’aider les musulmans à réciter quotidiennement les adhkar authentiques du matin et du soir, tout en comprenant leur sens et leurs mérites.

Fonctionnalités principales

1. Accueil

Afficher :

Adhkar du matin

Adhkar du soir

Dernière lecture

Progression quotidienne

Temps restant avant le prochain adhkar

Citation du Coran ou Hadith du jour



2. Liste des Adhkar

Chaque dhikr doit comporter :

Texte arabe

Écriture arabe parfaitement vocalisée.

Phonétique

Exemple :

Allahumma bika asbahna wa bika amsayna…



Traduction française

Traduction claire.



Explication

Expliquer :

le sens

dans quelles situations le réciter

ce qu’il apporte

pourquoi le Prophète ﷺ le récitait



Mérites

Ajouter les hadiths authentiques :

protection

pardon

récompense

éloignement du Shaytan

sérénité

invocation exaucée

protection jusqu’au soir ou jusqu’au matin

Avec les références :

Sahih Muslim

Sahih al-Bukhari

Abu Dawud

At-Tirmidhi

An-Nasa’i

Ne jamais utiliser de hadith faible.



3. Compteur intelligent

Chaque dhikr possède son propre compteur.

Exemple :

À réciter :

3 fois

Le compteur affiche :

○○○

Après chaque clic :

●○○

Puis :

●●○

Puis :

●●●

Quand terminé :

✅ Dhikr terminé

Possibilité de :

remettre à zéro

augmenter

diminuer

Animation fluide.



4. Barre de progression

Afficher :

Progression du matin

0 %

25 %

50 %

75 %

100 %

Même chose pour le soir.



5. Notifications

Notifications personnalisables :

Après Fajr

Avant le lever du soleil

Après Asr

Après Maghrib

Avant de dormir

Personnalisation des horaires selon la localisation.



6. Favoris

Pouvoir enregistrer des adhkar favoris.



7. Recherche

Recherche par :

mot arabe

mot français

phonétique

référence du hadith
